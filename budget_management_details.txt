Budget Management System - Detailed Documentation

1. Budget Creation Flow
-----------------------
The budget creation process is managed by the BudgetOnboarding component (app/tabs/budget/onboarding/BudgetOnboarding.tsx) and consists of 4 main steps:

a) BasicInfoStep:
- Collects fundamental budget information:
  * Budget name (with validation for uniqueness)
  * Budget period (monthly, weekly, yearly)
  * Start date
- Validates budget name against existing budgets in Firestore
- Provides real-time validation feedback

b) IncomeStep:
- Handles income sources configuration:
  * Supports multiple income types (salary, pension, freelancing, investments, scholarship, other)
  * Each income type has an amount field
  * Real-time total income calculation
  * Visual feedback with icons for each income type

c) ExpensesStep:
- Manages expense categories and subcategories:
  * Predefined categories with customizable subcategories
  * Amount allocation for each subcategory
  * Real-time validation against total income
  * Visual feedback for remaining budget
  * Category selection with toggle functionality

d) SummaryStep:
- Provides final review before saving:
  * Displays complete budget overview
  * Shows total income and expenses
  * Calculates remaining budget
  * Final validation before saving

2. Budget Storage and Data Structure
-----------------------------------
The budget is stored in Firestore with the following structure:
{
  userId: string,
  name: string,
  period: string,
  startDay: string,
  incomes: Array<{
    type: string,
    amount: string
  }>,
  categories: Array<{
    name: string,
    subcategories: Array<{
      name: string,
      amount: string
    }>
  }>,
  amount: number,
  createdAt: timestamp
}

3. Budget Management Features
----------------------------
a) Budget Selection:
- BudgetSelector component allows switching between multiple budgets
- Supports creating new budgets
- Enables budget deletion with confirmation
- Persists selected budget in AsyncStorage

b) Budget Editing:
- EditBudget component provides comprehensive editing capabilities:
  * Modify income amounts
  * Add/remove income sources
  * Adjust category and subcategory amounts
  * Add/remove subcategories
  * Real-time updates to Firestore

c) Visual Feedback:
- Progress bars for budget utilization
