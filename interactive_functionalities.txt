Interactive Functionalities

1. Quest Generation and Management
--------------------------------
a) Quest Generation Logic:
- Implemented in QuestService.generateQuests()
- Generates quests based on user spending analysis
- Types of quests:
  * Daily: Keep spending under average daily amount
  * Weekly: Reduce weekend spending
  * Monthly: Long-term financial goals

b) Quest Personalization:
- Based on user's spending patterns
- Difficulty adjusted to user's level
- Category-specific challenges
- Dynamic target amounts based on historical data

c) Quest Structure in Firestore:
```typescript
interface UserQuest {
    id: string;
    userId: string;
    title: string;
    description: string;
    type: 'daily' | 'weekly' | 'monthly' | 'achievement';

    progress: number;
    target: number;
    status: 'active' | 'completed' | 'claimed' | 'failed' | 'locked';
    category?: string;
    startDate: Date;
    endDate?: Date;
    streak?: number;

    claimedAt?: Date;
}
```

b) Progress Tracking:
```typescript
async trackExpense(userId: string, expense: Expense): Promise<void> {
    const activeQuests = await this.getActiveQuests(userId);
    const batch = writeBatch(db);
    
    for (const quest of activeQuests) {
        let shouldUpdate = false;
        let newProgress = quest.progress;
        
        // Update progress based on quest type
        switch (quest.type) {
            case 'daily':
                if (new Date(expense.date).toDateString() === now.toDateString()) {
                    const todayExpenses = await this.getTodayExpenses(userId);
                    newProgress = todayExpenses.reduce((sum, exp) => sum + exp.amount, 0);
                    shouldUpdate = true;
                }
                break;
            // Other quest types...
        }
        
        if (shouldUpdate) {
            const questRef = doc(this.questsCollection, quest.id);
            const newStatus = newProgress >= quest.target ? 'completed' : 'active';
            batch.update(questRef, {
                progress: newProgress,
                status: newStatus
            });
        }
    }
    
    await batch.commit();
}
```
